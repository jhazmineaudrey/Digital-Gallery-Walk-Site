# Digital Gallery Walk Site
A simple website solely developed by Jhaz. It elegantly displays different artworks (placeholder artworks, since I wouldn't really want to show my classmates' personal information found on it) according to different categories, and even allows the user to download said artworks. It also presents and makes clear the different roles and credits each member of the class has in contributing towards the Gallery Walk.

## Features
**I. Smooth Animations**
- A unique and interactive landing page animation
- Website element animations

**II. Viewable/Downloadable Artworks**
- Appropriately and aptly displays the different chosen artworks
- Zoom in/out function on each of the artworks
- Ability to download the selected artwork

**III. Credits/Role Display**
- Efficiently displays the roles/contributions of each participant of the Gallery Walk.
- Hyperlinks to the art each chosen artist

**IV. Miscellaneous**
- Responsive Design (Allows for compatibility with typical smartphones, tablets, and laptops)
- Header with quick links to each of the different sections of the website
- Footer with copyright and more quick links (social medias, relevant links, hyperlinks to other sections on the website)

## Reason for Development
My current class has a project where we display the artworks we've made for a specific project in person for other classes to see. My teacher also stated that she'd really wished they could stay on display for longer, but unfortunately 2 weeks is the maximum time. This got me thinking; as a programmer, I could definitely find a way to cement or immortalize the Gallery Walk — via an online version of it being deployed online. I've also just *really* wanted to find an excuse to code something for academics since I enjoy coding so much, and really want to integrate my studies into it.

## How to Use the Program
1. Access the website's page on https://jhazmineaudrey.github.io/Digital-Gallery-Walk-Site/. No need to install anything on your local device.
2. Explore the site and view beautiful artworks.
3. Choose to download any artworks you find beautiful and worthy to keep on your device.
4. View the credits to see the roles and contributions of each member of the Gallery Walk.
